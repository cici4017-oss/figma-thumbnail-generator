# templates/

## 썸네일_자동화_요청서.xlsx

썸네일 자동화 요청에 사용할 표준 Excel 템플릿. 기존에 받던 지저분한(병합 셀, 채널명 안에
수량/옵션이 뒤섞인) 작업지시 양식을 해석하는 대신, 자동화가 직접 읽기 쉬운 표준 양식을
먼저 정의하고 그 규격만 지원하기로 한 결정에 따른 산출물이다.

시트 구성:
- `01_작업요청` — 실제로 입력하는 시트. 작업ID(=썸네일 1개) 단위로 행을 작성하고,
  혼합상품은 같은 작업ID에 순번을 나눠 여러 행으로 작성한다.
- `02_상품목록`, `03_채널목록` — 자동화 기준 데이터(드롭다운의 원천). 시트 보호가 걸려 있고
  탭 색이 빨간색으로 구분된다. 직접 수정하지 않는다.
- `04_작성가이드` — 작성 규칙 설명.

셀 병합을 전혀 사용하지 않는다 — 향후 Figma Plugin/Web이 이 파일을 기계적으로 파싱하기 쉽게
하기 위한 핵심 제약이다.

## 재생성 방법

```bash
npm run generate:template
```

내부적으로 `packages/core/scripts/generateWorkOrderTemplate.mjs`를 실행해서 이 파일을 다시
만든다. 상품/채널 목록이나 컬럼 구성을 바꿀 때는 이 스크립트를 수정하고 다시 실행한다.

## 상태

이 템플릿을 읽는 parser는 아직 구현하지 않았다 (레거시 양식용 파서는
`packages/core/src/import/`에 있지만, 이 표준 템플릿 전용 파서는 별도로 만들 예정).
